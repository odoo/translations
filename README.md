# Odoo Translations

This repository contains a mirror of the translation files of each Odoo repository whose translations are managed on [Weblate](https://translate.odoo.com). Weblate works exclusively on this repository and translations are synced back to the respective repositories automatically on a regular basis.

Translations branches are named `owner/repo/branch`, like e.g. `odoo/odoo/20.0` or `odoo/enterprise/saas-19.4`.
